Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

## Pacotes e dependências

- **Prefira módulos oficiais `expo-*`** e APIs documentadas no SDK antes de bibliotecas de terceiros.
- Instale com **`bunx expo install <pacote>`** (não `bun add` direto) para garantir versão compatível com o SDK 57.
- Consulte guias em https://docs.expo.dev/guides/ antes de adicionar dependência nova.
- Regra Cursor completa: [`.cursor/rules/mobile-expo-packages.mdc`](.cursor/rules/mobile-expo-packages.mdc).
